### Ручная проверка двух участков (шаг 6)

1. **`CourseService.searchByTitle`** (обработка внешних данных) — подтвердил(а) находку SAST: строка из запроса без валидации попадает в SQL. Совпадает с выводом SAST (ERROR).
2. **`AuthController.doLogin` / `register`** (авторизация) — вручную: сравнение паролей открытым текстом, пароль в логе, роль выбирается клиентом при регистрации. SAST это правило не покрывает — записано как ручные находки; исправление лога внесено, хранение паролей и выбор роли зафиксированы для дальнейших работ.
